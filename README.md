# Fast VPN Business

Разворачивает VPN-сервис под ключ на Linux: панель [Remnawave](https://docs.rw), ноды, страницу подписок и Telegram-бота для продажи подписок. Всё ставится через консольное меню, бот работает под любым вашим названием.

Бот вырос из действующего сервиса: он работает с февраля 2026 года и обслуживает 500+ пользователей.

## Что устанавливается

| Компонент | Что делает |
|---|---|
| **Remnawave Panel** | Панель управления пользователями и нодами (Docker Compose). |
| **Caddy** | Автоматический HTTPS для панели и страницы подписок. |
| **Subscription Page** | Публичная страница подписки, скрывает домен панели. |
| **Node** | Подключает VPN-сервер (Xray-core) к панели. |
| **Caddy Selfsteal** | Маскировка Reality: настоящий HTTPS-сайт (один из 11 шаблонов) на порту `dest`. |
| **Telegram-бот** | Продажа подписок, тарифы, оплата, удержание клиентов, антиабуз и админка. |

## Быстрый старт

На чистом сервере Ubuntu или Debian под root:

```bash
curl -fsSL https://raw.githubusercontent.com/yaceluyudevochek/fast-vpn-business/main/install.sh -o install.sh
sudo bash install.sh
```

```
1) Установить Remnawave Panel + Subscription Page
2) Подключить этот сервер как ноду
3) Caddy Selfsteal (маскировка Reality для ноды)
4) Установить Telegram-бота (white-label)
5) Полная установка на этом сервере (панель + sub-page + бот)
6) Очистка / удаление установленного
7) Выход
```

Панель, ноды и бот обычно живут на разных серверах, поэтому запустите `install.sh` на каждом и выберите его роль.

1. **Сервер панели: пункт `1`.** Введите домен панели и, если нужно, страницы подписок. Docker, панель, Caddy и SSL поднимутся сами.
2. **Серверы нод: пункт `2`.** Добавьте ноду в панели (Nodes → Management → `+`) и вставьте её `docker-compose.yml` по подсказке. Здесь же пунктом `3` можно поднять Caddy Selfsteal.
3. **Сервер бота: пункт `4`.** Мастер спросит токен бота, адрес и ключ панели, реквизиты Platega.io и ссылки, соберёт `config/config.py` и запустит службу `fastvpnbot`.

Для одного сервера есть пункт `5`.

### После установки бота

1. Откройте `/admin` → типы тарифов и укажите настоящий `squad_id` из панели: при первом запуске там заглушка, и без настоящего значения подписки не выдаются.
2. Настройте тарифы: цены, число устройств, описание, коэффициент смены тарифа. Коэффициент удобно задать равным месячной цене. **Тариф с ID 1 считается базовым:** на нём выдаётся триал, а бонусные дни задаются в его днях.
3. По желанию включите белые списки и возврат клиентов (см. ниже). По умолчанию они выключены.

## Возможности бота

**Продажа**
- Одна подписка на аккаунт. При смене тарифа оставшиеся дни не сгорают, а пересчитываются по коэффициенту.
- Триал, продление, тарифы с лимитом и без лимита трафика, планы на разные сроки.
- Оплата через Platega.io (СБП, криптовалюта). Повторный вебхук не продлевает подписку второй раз.
- Промокоды: процент скидки, выбор тарифов и планов, срок, лимит активаций, «только первая покупка», один раз на человека. Рекламные коды со статистикой для расчётов с партнёрами.
- Реферальная программа: награда начисляется, только когда друг реально подключился к серверу.

**Белые списки**
- Отдельный Internal Squad с лимитом трафика по тарифу. Бот сам выдаёт и снимает сквад, остальные сквады пользователя не трогает.
- Каждый день подписки даёт лимит тарифа / 30 ГБ. Оплаченные дни дают полный лимит на каждые 30 дней, бонусные начисляют ГБ за эти дни.
- Предупреждение на 80%, глобальный выключатель, ручное управление сквадами и обнуление трафика из админки.

**Удержание**
- Напоминания об окончании подписки: за 24 часа, за час, за 10 минут и после окончания. После перезапуска бота не дублируются.
- Возврат клиентов: подарок не продлившим, цепочки для тех, кто нажал `/start` и не взял триал, помощь тем, кто не подключился. Не больше одного сообщения в сутки, только днём.
- Рассылки по аудиториям, с подарком дней: дни и ГБ пересчитываются под тариф каждого получателя, повторное нажатие не начисляет дважды.

**Антиабуз**
- Оповещения админам: аномальный трафик, общие устройства или IP у разных аккаунтов, больше одновременных подсетей, чем позволяет лимит устройств.
- Один триал на устройство: повторный на том же HWID завершается.

**Самообслуживание и админка**
- Перевыпуск ссылки подписки (пользователю раз в сутки, админу без ограничений), сброс устройств, инструкция по подключению.
- Управление пользователями, днями, сквадами и тарифами, поиск Telegram ID по username, бэкапы из меню.

**Эксплуатация**
- Ежедневный согласованный бэкап базы с отправкой файла админу в Telegram и ротацией на сервере.
- Оповещения: нода или панель недоступна и снова в строю, ошибки оплаты, всплеск ошибок в логах.
- Версионные миграции базы применяются при запуске.

Картинки экранов необязательны: без них бот отправляет обычный текст. Как добавить свои: [bot/assets/images/README.md](bot/assets/images/README.md). Тексты возврата клиентов лежат в `bot/services/retention_texts.py`, их стоит переписать под свой сервис.

## Настройка

Мастер создаёт только обязательные настройки. Остальные можно добавить в `/opt/fastvpnbot/config/config.py`, полный список с описаниями есть в [`config.py.example`](bot/config/config.py.example).

| Настройка | По умолчанию | Что задаёт |
|---|---|---|
| `BS_SQUAD_UUID` | пусто (выключено) | Internal Squad с серверами белых списков |
| `RETENTION_GIFT_DAYS` | 3 | Подарок при возврате, в днях базового тарифа |
| `ABUSE_DAY_GB`, `ABUSE_WEEK_GB` | 50, 200 | Порог аномального трафика |
| `REFERRAL_WAIT_DAYS` | 3 | Сколько ждать подключения друга |
| `TRIAL_BY_DEVICE` | `True` | Один триал на устройство |
| `BACKUP_HOUR_MSK`, `BACKUP_KEEP_DAYS` | 4, 14 | Время бэкапа и срок хранения |
| `MONITOR_INTERVAL`, `MONITOR_IGNORE_NODES` | 300, `[]` | Частота проверок и ноды-исключения |

После правки конфига выполните `systemctl restart fastvpnbot`.

## Caddy Selfsteal

Reality прячет трафик за настоящим TLS-рукопожатием, но за портом `dest` должен быть реальный сервер, который ответит настоящим HTTPS всем остальным. Этим сервером и служит Caddy Selfsteal. Он ставится на сервер ноды пунктом `3`:

- домен сертификата должен совпадать с `serverNames` в инбаунде;
- сертификат обычный (HTTP-01) или wildcard через Cloudflare DNS-01;
- HTTPS-порт по умолчанию `9443`;
- шаблон сайта можно сменить в любой момент без переустановки.

После установки скрипт печатает значения для инбаунда:

```json
{
  "serverNames": ["your-domain.com"],
  "dest": "127.0.0.1:9443",
  "xver": 0
}
```

## Разработка и обновление

```bash
cd bot
python3 -m venv venv && venv/bin/pip install -r requirements
venv/bin/python tests/run_all.py     # тесты на временных базах, настоящий конфиг не нужен
```

Выкладка изменённых файлов на сервер со своей машины. Скрипт запускает тесты, сравнивает файлы с сервером, делает бэкап базы и кода, загружает, перезапускает службу и проверяет логи:

```bash
DEPLOY_HOST=root@1.2.3.4 bot/scripts/deploy.sh
DEPLOY_HOST=root@1.2.3.4 bot/scripts/deploy.sh rollback code_before_<коммит>_<время>   # откат кода
```

Нужен вход на сервер по SSH-ключу. Обновить бота можно и через установщик: `cd /opt/fast-vpn-business && git pull && sudo bash install.sh`, пункт `4`. Конфиг и база при этом сохраняются.

## Смена IP-адреса ноды

Если хостер выдал ноде новый IP (например, старый перестал открываться у пользователей):

1. Укажите новый IP в A-записи домена Selfsteal и дождитесь, пока DNS обновится.
2. В панели поменяйте адрес у ноды и у всех её хостов. Если нода стоит за мостом — ещё и адрес в outbound профиля моста.
3. На ноде обновите строку `# Server IP` в `/opt/caddy/.env`; домен остаётся прежним, сертификат перевыпускать не нужно.
4. Попросите пользователей обновить подписку в приложении.

Проверяйте доступность настоящим TLS-подключением из нужного региона, а не только TCP: при выборочной блокировке соединение по TCP устанавливается, а рукопожатие TLS обрывается.

```bash
echo | openssl s_client -connect <новый IP>:<порт> -servername <домен Selfsteal> 2>/dev/null | grep -c "BEGIN CERTIFICATE"
```

## Требования

- Ubuntu 22.04+ или Debian 11+.
- Панель: от 2 ГБ RAM, 2 CPU, 20 ГБ диска. Нода: от 1 ГБ RAM, 1 CPU.
- Домен для панели, при необходимости отдельный для страницы подписок и для Selfsteal.
- Токен Telegram-бота и аккаунт Platega.io.

## Безопасность

- Установщик работает под root, секреты остаются на сервере в `.env` и `config.py` и никуда не передаются.
- `config/config.py` не хранится в git.
- Порт ноды стоит открыть файрволом только для IP панели.
- Файл бэкапа содержит данные пользователей и приходит в Telegram админу: `BACKUP_CHAT_ID` должен указывать только на доверенного человека.
- Очистка необратима: каждый шаг требует ввести слово `УДАЛИТЬ`.

Используя проект, вы сами отвечаете за соблюдение законов своей страны и условий хостеров и платёжных систем.
